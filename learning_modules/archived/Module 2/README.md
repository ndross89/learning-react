# Module 2 — First Project Review

**Status:** recap  
**Time:** ~half day  
**Build:** none required. This is a guided look at code you already wrote.

The original Module 2 asked for a static `UserCard`. You skipped that and built something bigger: props, a list, `useState`, and a click handler in one pass. This module names what that code already is, and flags JSX habits to tighten before Watchlist.

Source: [docs/react-learning-roadmap.md](../../docs/react-learning-roadmap.md)

## What you will be able to explain

1. The component tree of `first-project` (who rendered whom).
2. The JSX rules you already used (`className`, `{ }`, fragments, capital vs lowercase tags).
3. Three specific nits in `Card.jsx` / `App.jsx` (`typeof`, extra fragments, mixed hardcoded + mapped cards).
