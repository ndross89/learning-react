# React Project Setup

Guide for scaffolding a React learning project with **Vite** and **JSX** (JavaScript). React’s docs recommend Vite when you want to learn React itself (routing, data fetching, and other app concerns come later).

This repo uses **JSX, not TypeScript**.

Create React App (CRA) is deprecated for new apps — do not use it.

## Prerequisites

| Tool | Notes |
| --- | --- |
| **Node.js** | LTS (v20 or newer). Check with `node -v` |
| **npm** | Bundled with Node. Or use `pnpm` / `yarn` / `bun` if you prefer |

Install Node from [nodejs.org](https://nodejs.org/) or via a version manager (`nvm`, `fnm`, `volta`).

## 1. Scaffold the project

From an empty repo root (this one):

```bash
npm create vite@latest . -- --template react
```

Or into a new folder:

```bash
npm create vite@latest learning-react -- --template react
cd learning-react
```

Other package managers:

```bash
pnpm create vite . --template react
yarn create vite . --template react
bun create vite . --template react
```

| Flag | Meaning |
| --- | --- |
| `.` or `learning-react` | Project directory |
| `--template react` | React + JavaScript / JSX (**this repo**) |
| `--template react-ts` | React + TypeScript (not used here) |

Interactive alternative (prompts for name and template):

```bash
npm create vite@latest
```

When prompted, choose **React** → **JavaScript**.

## 2. Install dependencies

```bash
npm install
```

What the template installs for you:

| Package | Role |
| --- | --- |
| `react` / `react-dom` | UI library and DOM renderer |
| `vite` | Dev server, HMR, production bundler |
| `@vitejs/plugin-react` | JSX transform + Fast Refresh |
| `eslint` + plugins | Lint rules for React / JSX |

No TypeScript packages — components live in `.jsx` / `.js` files.

## 3. Run the app

```bash
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`). Edits under `src/` hot-reload.

Other scripts from the template:

```bash
npm run build      # production build → dist/
npm run preview    # serve the production build locally
npm run lint       # run ESLint
```

## 4. Project layout (what matters)

```
.
├── index.html          # HTML entry; Vite injects the JS bundle here
├── package.json        # scripts + dependencies
├── vite.config.js      # Vite + React plugin
├── eslint.config.js    # ESLint flat config
├── public/             # static assets (copied as-is)
└── src/
    ├── main.jsx        # React root mount
    ├── App.jsx         # top-level component
    ├── App.css
    ├── index.css
    └── assets/
```

Entry flow: `index.html` → `src/main.jsx` → `<App />`.

Use `.jsx` for files that contain JSX; plain `.js` is fine for non-UI helpers.

## 5. Necessary configurations

These files are generated by the template. Know what each controls; change them only when you need to.

### `vite.config.js`

Enables the React plugin (JSX + Fast Refresh):

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

Common additions later: `server.port`, path aliases (`resolve.alias`), env prefixes.

### JSX transform

With `@vitejs/plugin-react` and the modern JSX transform:

- You can write JSX in `.jsx` files without `import React from 'react'`.
- You still import hooks and APIs you use: `import { useState } from 'react'`.

Example component:

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)
  return (
    <button type="button" onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  )
}

export default Counter
```

### ESLint (`eslint.config.js`)

Flat config with React Hooks and React Refresh rules. Run with `npm run lint`. Tighten rules as you get comfortable; don’t disable them wholesale.

### Environment variables

- Put client-visible values in `.env` as `VITE_*` (e.g. `VITE_API_URL`).
- Access in code via `import.meta.env.VITE_API_URL`.
- Never commit secrets. Keep `.env` out of git; use `.env.example` for placeholders only.

Example `.env.example`:

```bash
VITE_API_URL=http://localhost:3000
```

### Git ignore (minimum)

Ensure `.gitignore` includes at least:

```
node_modules/
dist/
.env
.env.*
!.env.example
```

## 6. Sanity check

After install:

1. `npm run dev` — app loads in the browser.
2. Edit `src/App.jsx` — page updates without a full refresh.
3. `npm run build` — completes without errors.
4. `npm run lint` — no unexpected failures.

## 7. Optional learning add-ons (later)

Install only when a lesson needs them:

```bash
# Client routing
npm install react-router

# Component testing (Vitest + Testing Library)
npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom

# CSS utilities (if you choose Tailwind)
npm install -D tailwindcss @tailwindcss/vite
```

Prefer learning core React (components, props, state, effects, lists, forms) before adding a framework like Next.js.
